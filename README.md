# mzera

A small, fast, keyboard-first photo & WebM viewer for Omarchy (Hyprland / Wayland).

Status: **planning**. Nothing runs yet. Start with `docs/explainer.html`
(open it in a browser) and `docs/PLAN.md`.

## What it is for

- open a folder recursively and just browse
- gallery: flat grid, or grouped by folder, with thumbnail zoom
- format filters (only JPEG, hide WebP, …) and WebM video
- fullscreen viewer with arrow keys, captions / metadata / clean modes, built-in key help
- follows the current Omarchy theme automatically
- launches from `Super+Alt+P`, the app launcher, Nautilus, or `mzera <dir>`
